## VISUELE IDENTITEIT

De website moet dezelfde premium uitstraling behouden als de huidige homepage.

Belangrijk:

- donkere premium uitstraling
- bergachtergrond behouden wanneer passend
- subtiele mist/wolken
- blauw als accentkleur
- veel witruimte
- professionele typografie

Voorkom:

- neon websites
- gaming stijl
- cyberpunk
- overmatige gradients
- drukke achtergronden
- template gevoel
