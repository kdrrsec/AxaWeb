# Internationalisatie (i18n)

AxaWeb is tweetalig: **Nederlands** (standaard) en **Engels**.

## Structuur

```
i18n/
  config.js      # locales, flags, routePaths, hreflang/OG
  routing.js     # localizedPath met EN-slugs + /en-prefix
  dictionary.js  # getMessages / createTranslator (build-time)
  seo.js         # canonical, hreflang, OG, JSON-LD, sitemap

messages/
  nl/            # Actieve NL-vertalingen
  en/            # Actieve EN-vertalingen

content/
  nl/            # Pagina-, project- en juridische content (NL)
  en/            # Pagina-, project- en juridische content (EN)
```

## Routing

| NL | EN |
|----|----|
| `/` | `/en` |
| `/diensten` | `/en/services` |
| `/websites` | `/en/websites` |
| `/webshops` | `/en/webshops` |
| `/hosting` | `/en/hosting` |
| `/onderhoud` | `/en/maintenance` |
| `/pakketten` | `/en/packages` |
| `/projecten` | `/en/projects` |
| `/projecten/{slug}` | `/en/projects/{slug}` |
| `/contact` | `/en/contact` |
| `/offerte` | `/en/quote` |
| `/privacy` | `/en/privacy` |
| `/cookies` | `/en/cookies` |
| `/algemene-voorwaarden` | `/en/terms` |
| `/disclaimer` | `/en/disclaimer` |

Flags in `i18n/config.js`:

- `languageSwitcherEnabled = true`
- `englishLocaleLive = true`

## Language switcher

- NL | EN in header (desktop + mobiel)
- Geen vlaggen
- Actieve taal via `aria-current`

## SEO

- Canonical per locale
- hreflang: `nl-NL`, `en`, `x-default`
- `html lang` + `data-locale`
- `og:locale` + `og:locale:alternate`
- Sitemap bevat beide locales met xhtml-alternates

## Generatie

`npm run build` genereert NL-pagina’s in de root en EN-pagina’s onder `en/`.
