# Internationalisatie (i18n)

Technische voorbereiding voor meertaligheid. **Alleen Nederlands is live.**

## Structuur

```
i18n/
  config.js      # locales, defaultLocale, languageSwitcherEnabled, englishLocaleLive
  routing.js     # localizedPath, resolveLocaleFromPath (as-needed prefix)
  dictionary.js  # getMessages / createTranslator (build-time)
  seo.js         # canonical, hreflang, locale/OG metadata

messages/
  nl/            # Actieve vertalingen (common, home, form)
  en/            # Placeholders (zelfde keys, lege strings)

content/
  nl/            # Pagina- en projectcontent (NL)
  en/            # Placeholders (null → fallback naar NL)
```

## Routing (later)

| Pad | Locale |
|-----|--------|
| `/…` | Nederlands (default, geen prefix) |
| `/en/…` | Engels (nog niet gegenereerd/live) |

Zet `englishLocaleLive = true` in `i18n/config.js` zodra EN-content klaar is. Dan verschijnen EN-hreflang tags.

## Language switcher

- Markup zit in header (generated pages + homepage).
- Verborgen via `languageSwitcherEnabled = false` en `hidden` + CSS.
- Activeer: `languageSwitcherEnabled = true` in `i18n/config.js` en rebuild.

## SEO

- Canonical per pagina
- `hreflang` (`nl` + `x-default`; EN zodra live)
- `html lang` + `data-locale`
- `og:locale` (+ `og:locale:alternate` wanneer EN live)

## Nieuwe taal toevoegen

1. Locale toevoegen aan `locales` in `i18n/config.js`
2. `messages/{locale}/*.json` kopiëren van `en/` en vullen
3. `content/{locale}/` vullen (of null laten voor NL-fallback)
4. Generator uitbreiden om die locale te emitteren
5. Switcher + `englishLocaleLive`/equivalente flag aanzetten
